## 📖 О проекте

**Vigil** — быстрый и лёгкий менеджер процессов для Windows в духе Process Hacker и AnVir.
Показывает, что происходит в системе прямо сейчас, и позволяет управлять процессами в пару кликов.

## ✨ Возможности

- 📋 **Список процессов в реальном времени** — обновление на лету
- 📊 **Мониторинг ресурсов** — загрузка CPU и памяти по каждому процессу
- 🔍 **Детальная информация** — PID, путь к файлу, приоритет, число потоков
- ⚡ **Управление процессами** — завершение, смена приоритета, переход к файлу
- 🔎 **Поиск и фильтрация** — быстрый поиск процесса по имени
- 🌳 **Дерево процессов** — наглядная иерархия «родитель → потомки»
- 🖥️ **Нагрузка на систему** — общий мониторинг CPU и RAM

## 📦 Установка

1. Скачай `Vigil.exe` из раздела [**Releases**](https://github.com/sxrozs/Vigil/releases/tag/v1.0.0)
2. Запусти — установка не требуется (portable)

> ⚠️ Некоторые антивирусы могут реагировать на программы, работающие с процессами. Это ложное срабатывание — исходный код открыт.

## 🛠️ Сборка из исходников

Требуется **Qt** и компилятор C++ (MSVC или MinGW).

```bash
git clone https://github.com/sxrozs/Vigil.git
cd Vigil
qmake
make
```

Или открой `.pro` / `CMakeLists.txt` в **Qt Creator** и нажми **Build**.
